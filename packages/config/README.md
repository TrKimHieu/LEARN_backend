# @learn/config — cấu hình dùng chung

- `eslint/config.mjs` — luật lint; `eslint/boundary-rules.mjs` — luật **ranh giới** (không import chéo feature/domain)
- `typescript/` — `base`, `nestjs`, `nextjs`
- `tailwind/theme.css` — **token thiết kế** (màu, bo góc, bóng, font); sửa giao diện toàn cục ở đây
- `prettier/`, `vitest/` — định dạng và cấu hình test
